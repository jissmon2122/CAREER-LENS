# Job Market Datasets Directory

This folder contains raw and processed job market datasets used for training and testing future AI/ML engines.

## Directory Layout
- `raw/`: Stores raw CSV files (`sample_jobs.csv`).
- `processed/`: Destination for cleaned, feature-engineered datasets generated by future ML preprocessors.

## Sample Dataset Summary (`raw/sample_jobs.csv`)
- **Type**: Synthetic benchmark dataset
- **Size**: 30 records
- **Fields**: `job_id`, `job_title`, `company`, `location`, `salary_min`, `salary_max`, `job_description`, `skills`, `experience`, `industry`, `posted_date`
- **Notice**: Created specifically for baseline testing during Phase 1 development. Contains no proprietary or confidential corporate data.
